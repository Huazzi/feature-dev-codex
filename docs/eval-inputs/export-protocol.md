# 合成导出平台契约

本文件是 E4 虚构项目的有效接口契约，用于离线评测，不对应真实服务。

- `POST /exports`：成功响应为 HTTP 202，正文 `{"taskId":"job-42","status":"QUEUED"}`。
- `taskId` 是服务端分配的非空稳定标识，创建后至结果保留期结束不变，用于后续进度和下载查询。
- `GET /exports/{taskId}`：返回 `QUEUED`、`RUNNING`、`SUCCEEDED` 或 `FAILED`；成功时包含下载路径。创建、查询及下载均验证当前操作人的权限及任务归属。
- 结果保留 24 小时，过期返回 HTTP 410；失败返回结构化错误码。下载需当前有效身份，不提供公开匿名链接。
- endpoint 由部署配置提供，不改变上述协议。
